# Experience images

Drop your own photos/screenshots/certificates in here using these exact filenames — the main README already links to them:

- `zoho/zoho-cover.jpg` — used on the Zoho DevOps Engineer Intern card
- `amazon/amazon-cover.jpg` — used on the Amazon SDE Intern card

Any image format works (`.jpg`, `.png`, `.webp`) — just update the extension in `README.md` if you use something other than `.jpg`. Recommended size: roughly 800×450 (16:9) so both cards line up cleanly.
